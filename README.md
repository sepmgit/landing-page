# 🍷 Sergio Pantoja — Landing Page Minimalista

Landing page personal minimalista de **un solo Hero**, diseñada para **Sergio Pantoja** (Programador y Desarrollador Web). El proyecto destaca por su arquitectura semántica en **HTML5**, estilos modernos en **CSS3** y una identidad visual personalizada en tonos **vinotinto** sobre fondo oscuro.

## ✨ Características Principales

* **Diseño Minimalista de Único Hero:** Experiencia centrada en pantalla completa (`min-h-screen`) sin distracciones, enfocada directamente en la propuesta de valor.
* **Cabecera Ultra Limpia:** Navegación superior despejada con el isotipo SVG personalizado a la izquierda y acceso directo al contacto a la derecha.
* **Identidad Visual en Color Vinotinto:** Paleta de colores personalizada con gradientes vinotinto (`#380513` a `#df4a70`) y efectos de iluminación ambiental sutil.
* **Logo Vectorial Personalizado (SVG):** Escudo hexagonal con monograma geométrico `S` y corchetes de código (`< S >`), integrado tanto en la barra superior como en el *favicon* del navegador.
* **100% Responsivo (Mobile-First):** Adaptación fluida a dispositivos móviles, tablets y pantallas de escritorio.
* **Contacto Rápido Integrado:** Modal interactivo con formulario de contacto directo y notificaciones flotantes (*toast*) sin recargar la página.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica limpia y accesible.
* **CSS3 & Tailwind CSS:** Diseño moderno, sistema de rejillas, efectos *backdrop-blur* y animaciones suaves.
* **SVG Inline:** Gráficos vectoriales escalables de alto rendimiento sin dependencias externas.
* **JavaScript (Vanilla):** Control del modal de contacto, validación de formulario y sistema de alertas *toast*.
* **Font Awesome & Google Fonts:** Tipografías *Inter* y *Fira Code* junto con iconografía técnica.

## 🚀 Instalación y Uso Local

No requiere procesos de compilación ni instalación de paquetes externos.

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/sepmgit/landing.git
   ```

2. **Ingresa al directorio del proyecto:**
   ```bash
   cd landing
   ```

3. **Abre el proyecto:**
   Simplemente haz doble clic sobre el archivo `index.html` o ábrelo con la extensión **Live Server** en Visual Studio Code.
